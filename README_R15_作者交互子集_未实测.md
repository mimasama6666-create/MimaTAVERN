# 咪嘛馆 R15 · 作者交互宿主 v1 · 仅静态检查候选版

这是 R15 的历史交接说明。当前覆盖包新增的离线库、事件、Zod 管理器和快捷回复请看 `README_R16_酒馆与高级插件适配_未实测.md`；下方未实现列表描述 R15 当时的状态。

完整覆盖包包含 R14.2 的手动恢复和 R14.1 的正则保存修正。本轮继续实现上轮蓝图里的作者交互链，不修改 MIMAMAO、QQBOT，不部署、不推送。

**只完成源码、语法和静态调用链核对；未运行测试、浏览器、匿名卡实机或真实模型验证。不能称作酒馆完全体或实机验收通过。**

## 本轮新增入口

进入酒馆故事 →「正则与外观」里的互动功能 →「作者交互宿主 · v1 子集」。每项列出原始来源 SHA、资源 ID、脚本路径、脚本 ID、代码 SHA；源码按需展开。权限默认不勾选，只有手动确认后运行。

旧 Worker 和旧可视化模式保留；旧授权不升级。刷新、离开故事、返回故事库、撤权与手动恢复原回复时停止作者页面，已提交变量保留。刷新后不会自动重跑作者 JS。

## 代码实现的接口范围

| 接口 | 本版范围 |
| --- | --- |
| `getVariables({type})` | 同步返回深复制快照；明确指定 chat / message / script |
| `replaceVariables(value, option)` | 同步返回 void；本动作立即可读待提交值，异步原子保存 |
| `updateVariablesWith(fn, option)` | 同步或异步 updater；异步冲突明确报错 |
| `getChatMessages(range, options)` | 同步已提交楼层视图；整数、负数、闭区间、role/hide_state 筛选；安全 extra 与本楼变量 |
| `getScriptId()` / `getLastMessageId()` | 当前脚本 ID / 已授权快照末楼号 |
| `MimaAuthor.whenCommitted()` | 咪嘛馆自己的回执等待接口，不冒充原版 API |

消息写入使用稳定内部 ID；楼层号只用于已验证快照中的寻址。`getChatMessages` 的 `data` 字段需要同时勾选消息正文读取和楼层变量读取。读失败、坏记录或来源变化会报 unavailable，首次空表必须单独授权初始化，不覆盖旧表。

参考类型声明锁定 Tavern Helper 4.11.3 / `a0f3a180344cff38a4b3e75041d5a94380b877d6`；实际能力版本是 `mima-author-host/1`，不是完整酒馆助手 4.11.3。

## 状态进入 Prompt

仅在派生请求中解析以下宏，原卡和 canonical History 不改写：

- `{{get_chat_variable::score}}`：本故事 score；支持安全点路径与 JSON 值。
- `{{get_message_variable::score}}`：历史消息宏按原消息稳定 ID 读取；其它提示词使用最近已提交楼层。
- `{{get_message_variable::score::-1}}`：显式指定快照中的楼层。

发送、续写、重试、请求预览和分支前，暂停新作者写入，等待本动作回执；失败或无回执则明确阻止，不调用模型，玩家输入保留。形成请求后不修改该请求。作者状态只通过这些明确宏进入模型，不自动混入 MVU 或角色记忆。

Store 在同一事务验证来源授权、消息/ledger 指纹、全部已读取变量表的修订以及每个写表的修订，再写变量和去重回执。纯设置或其它脚本私表的变化不伪装成原文变化；只在完整读取集仍一致时允许提交。每次操作的稳定 ID 由 Host 生成，相同 ID 不同内容拒绝。

## 分支、备份与回退

分支同事务复制相应节点的已提交变量，消息变量重映射为新消息 ID；节点之后的作者修改按操作回执回溯，不复制未提交值。父故事不变，执行授权不复制。完整兼容备份保留新记录；恢复时验证表、来源、回执、消息外键，新导入的作者执行授权一律要求重新授予。

没有升级数据库版本。包内 `_R15_rollback/` 是本次修改前的 R14.2 程序文件；覆盖回同级程序目录并重新加载即可停用新宿主。新文件可保留在目录中但不会被旧 index 引用。不要清空浏览器数据。旧版不理解新变量，已保存的新记录会保留供再次升级读取。

## 明确还没做的部分

完整 jQuery / Vue / Zod、外部模块和素材依赖加载、全局/预设/角色/扩展变量、作者正文创建/删除/改写、swipes、原版自动事件和完整 Quick Reply / STscript 尚未实现。原版作者卡如果依赖这些接口仍可能报错，源码继续保留，不放同名空壳假装兼容。

作者 DOM 是 `sandbox=allow-scripts` 的独立页面，无 same-origin、宿主 DOM/存储/密钥、网络、导航或模型权限。可信 JS 仍可能写出死循环；iframe 和超时不能保证硬终止浏览器卡顿。4 秒回执期限只用于作者初始化/保存握手，不会重试或取消玩家模型请求。

`examples/作者变量按钮_v1.json` 是可选的中性演示素材，可读取和改变三种变量并查看请求预览；它没有在本轮执行，不能充当验收证据。
