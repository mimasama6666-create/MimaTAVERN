MIMAMAO Tavern · v1.1.6
PERSONA MACRO RESOLVER HOTFIX

基线
----
唯一施工基线：MimaTAVERN-main-v1.1.5-FULL.zip
本轮为增量 Hotfix；未重构成熟 Store / Regex / Assistant Studio / Font / CSS / 使用手册。

问题
----
旧版虽然在 Preset / Regex / Persona 中允许书写 {{user}} / {{char}}，但 Core 没有真正的 Persona Macro Resolver。
因此：
1. {{user}} / {{char}} 可能原样进入模型 Prompt；
2. Base System 长期使用 “User Persona / Character Persona / 不要替 User …” 等内部术语，容易让模型把 User 当人物姓名；
3. display-phase Regex replacement 中的 {{user}} / {{char}} 不会在前端展开；
4. Worldbook depth injection、Memory / Summary 材料也可能继续携带未解析占位符或内部 User/Character 标签。

v1.1.6 施工
--------------
1. 新增 persona-macro-resolver.js Sidecar
   - {{user}} -> 当前已挂载 User Persona 的 name
   - {{char}} -> 当前已挂载 Character Persona 的 name
   - 大小写与宏内部空格兼容，例如 {{USER}} / {{ char }}
   - 未挂玩家 Persona 时 fail-soft 为“你”
   - 未挂角色 Persona 时 fail-soft 为“角色”
   - 只处理自然语言字符串；不触碰 API role、ID、Store key、schema、transport 字段。

2. Prompt Assembler 接入 Macro Resolver
   - Persona description/content/scenario/example dialogue
   - Preset content
   - Worldbook Front / Middle / Back
   - Worldbook depth injection
   - Pinned Facts
   - Rolling Summary / Scene Summary / Relationship Summary
   - Core Memory / Fact Memories
   - User Notes / AI Notes / Director Note
   - 最近剧情消息在 prompt-phase Regex 后再解析宏
   均以“读取/组装时解析”的方式工作；源 Store 不做破坏性迁移。

3. Base System 去除会教坏模型的自然语言 User/Character 称呼
   - 改为“当前玩家 Persona / 当前角色 Persona”
   - 明确当前玩家名与当前角色名
   - 明确接口内部玩家消息角色标识只是 transport metadata，不是人物姓名
   - 明确旧剧情中残留的英文接口称呼属于旧格式错误，只继承事实，不继承称呼
   - 自动推进 / 导演注释改用解析后的玩家名

4. Display Regex 接入 Macro Resolver
   执行顺序：
   raw assistant output
   -> display Regex
   -> Persona Macro Resolver
   -> Safe HTML renderer
   因此 replacement 中：
   <span>{{user}}</span>
   会真正显示当前玩家 Persona 名称，而不是 {{user}} 或 User。

5. Memory summary 输入去内部角色标签
   事实记忆 / 核心记忆所使用的剧情时间线改用实际 Persona name 标记双方，不再把自然语言材料写成 User： / Character：。
   API 本身 role:'user' / role:'assistant' 仍保持 canonical，不做任何改名。

6. UI 小型一致性修复
   - 玩家消息 Header 无 Persona 时显示“你”，不再显示“你 / User（用户）”
   - 角色 Header fallback 改为“角色”
   - “User（用户）备注”显示文案改为“玩家备注”
   - 编辑分支确认文案改为“玩家消息”
   只改显示文字，不改机器 role。
