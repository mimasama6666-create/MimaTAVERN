主库完整备份读取最新版、密钥与额外认证头导出保护、原生会话异步写回隔离；小说续写新章绑定及新鲜摘要过滤；助手独立会话挂载与恢复后迟到请求保护；手机归档、聊天附件可见性、录音线程身份、生成中发送锁；工坊字体与壁纸备份、旧草稿安全分叉、复杂背景纹样位置和兼容 HTML 合同字段保真。第一批修复继续保留。第二批补上滚动记忆失效重建、记忆提交参考校验、记忆独立模型容量身份、完整 HTML 续写二次验收、手机角色简介与评论记忆、手机钱包失败结算核对、世界书高级匹配、工坊异步目标归属、小说采纳与记忆错误分离、STscript 最新分支变量继承及双库恢复入口；第三批已将原生四阶段正则迁至隔离 Worker，为 STscript 新回合写入按回合快照，并修复助手生成中切换类型的错写风险。第五批改为逐章节、逐摘要和本轮指令计算小说世界书扫描深度；双库导出复核原生库的全部规范化快照内容而不只比较版本号；安全合并原生备份时保留无剧情库中已有的自定义主题。第四批把主剧情、小说、记忆的世界书激活匹配迁至可终止 Worker；记忆冻结匹配结果和激活来源，在 IndexedDB 最终事务中只执行确定性签名核对，不在事务里跑正则。事实记忆手动二次合并独立核对模型容量，候选创建和采纳均检查参考合同；旧候选无合同则需主人额外确认。双库备份现在核验完整快照内容，已写入成功但刷新失败会明确区分，不再诱导重复导入。历史旧回合没有快照时继续拒绝伪继承；所有能力仍需真实设备验证。
第六批专项修复
小说世界书匹配源按章节时间顺序排列，同章节先读取新鲜摘要、再读取原始正文，本轮导演指令最后进入匹配窗口；扫描深度 1 在无导演指令时优先检查当前章节正文。原生备份的「仅空库恢复」现在会识别只设置过主题或 CSS 的非空配置，不再静默覆盖；安全合并仍保留第五批的独立冲突判断。手动消息编辑、删除、新增开场、HTML 修复及失败正文恢复先在独立快照中操作，Worker 中断或数据库保存失败不再将未提交文本泄漏到主内存；最终仍由剧情修订号和数据库 CAS 决定是否成功。
第七批专项修复
面具、预设、世界书、CSS、正则和小说项目的保存与关联资源删除，统一从最新资料库创建独立草稿，以数据库事务提交为唯一成功依据；同时检查资源更新身份、小说修订号与同 ID 冲突。失败会保留旧数据，多窗口冲突不静默覆盖。主题仅在保存成功后应用，删除 CSS 后重新应用生效的主题；双库中的原生资料库恢复不再先修改活动内存状态。
第八批专项修复
工坊 CSS 发布、助手 CSS 发布、助手资源挂载和 Regex Bundle 的预设/规则联动均使用与剧情保存相同的数据库提交队列；发布失败不修改共享内存或错误重绘主题。删除面具、预设、世界书、CSS、正则时，在同一事务内解除剧情/小说/设置模板的失效引用并提升模板修订号，避免保留无法使用的模板。模板操作和模板建剧情也统一使用失败回读的提交机制，剧情 CAS 冲突后只读重载最新数据。旧面具、世界书及正则包缺少时间戳、旧规则缺少 ID 时采用稳定兼容身份，不再因多次标准化随机生成内容而误报修改冲突。
第八批安全基线 · 根因修复与性能施工（开发测试版）
外观字体选择改用已加载的字体元数据，避免每次进入外观界面重复复制完整字体文件；主题工坊连续滑动调整时合并预览绘制，保留实际样式与素材；剧情重绘不再反复序列化未改变的全部正则包，超长表单改为逐项比较。以上是针对性性能修复，已修复默认模板、旧 History 时间读取、小说世界书深度、空删除写盘、工坊菜单与手机设置触控问题；尚未完成真实 iOS 键盘和多标签持久库验收。没有删减 History、记忆、世界书或主题能力。
