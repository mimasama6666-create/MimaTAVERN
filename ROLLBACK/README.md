# 原生咪嘛馆前端回滚（保留数据）

`index-v1.4.0.html` 是 v1.4.0 母体中未经修改的原始页面；校验哈希见 `SOURCE-BASELINE.json`。新版本只添加独立兼容脚本及高级入口，其它旧文件保持一致。

回滚步骤：先在原生界面导出原生资料；如曾使用兼容实验室，也在高级界面分别导出兼容备份和双库备份。停止相关网页后，把 `index-v1.4.0.html` 复制到部署文件夹的 `index.html`（不要删除旧资料文件夹）。新加的 compat-*.js/CSS 可以原地保留，因为旧 index 不引用它们；不要清除浏览器网站数据，不得删除任意 IndexedDB。

Windows 可用 `Restore-Frontend.ps1 -TargetDirectory <静态网站目录>`；脚本会在目标旁先生成完整原 index 时间戳备份，绝不删除业务数据。此回滚不会自动卸载 SillyTavern sidecar，它有独立 Stop 和 Rollback 工具。

注意：如果新版已经在高级模式产生兼容剧情，恢复旧主页后新库仍存在，只是旧版 UI 不读取。要再次使用可重新部署新版静态页面；这是非破坏性回滚，不是把两种数据库合并。
