二、新增模块
- novel-engine.js: Novel Project / Chapter / Segment / Draft / Generation、TXT 分章、编辑、导出、visible-char 计数。
- novel-memory.js: ChapterSummary / NarrativeState 校验、增量 merge、stale 判定、manual overrides。
- novel-prompt-assembler.js: Novel-only Prompt、Preset / Worldbook、partial/stale memory 语义、上下文预算、Inspector。
- novel-studio.js: 三栏/移动端 Novel UI、导入、章节操作、续写、Draft/采纳、记忆、主题、导出。
- theme-engine.js: Default / Midnight / E-Ink / Paper。

三、Canonical 生命周期
- AI generation success != Draft acceptance != Memory settlement。
- minimumChars 由代码验证；不足时同一个 generation ID append，不重启整段。
- Draft 不进入 canonical 正文；只有 accept 能追加 ai_accepted segment。
- accept 先提交正文，再尝试 memory；memory 失败只标 degraded，不回滚已采纳正文。
- 修改/删除/重排旧章节会从第一个受影响章节向后 stale。
- 未分析章节是 missing/PARTIAL，不误判成 stale；stale global memory 不进入续写 Prompt。

四、UI / CSS
- Novel Studio 桌面：项目/章节、阅读器、剧情档案/设置三栏。
- 移动端：正文 / 剧情档案 / 设置切换。
- 阅读视图支持段距、行高、字距、首行缩进和最大宽度；编辑器折叠在阅读页内。
- CSS Preset 增加 novel / assistant surface，同时保留 story / global / app 旧 scope。
- CSS Assistant 获得稳定 Novel selector/token；Novel/Assistant CSS 不会自动误挂到当前 RP Session。
- Default Theme 不覆盖 v1.2 默认玻璃外观；Custom CSS 保持最后覆盖权。

五、兼容性
- library schema v3 -> v4 为 additive migration。
- Preset / Worldbook 删除时会同步解除 Novel 引用。
- CSS 删除会解除 Novel appearance 引用。
- 旧 RP processStoryTurn 调用链未改为 Novel 路径；Novel 为 sibling domain。
- 旧组件自身 ?v= 版本号保持；release cache marker 升为 1.3.0。

六、模拟验收期间发现并修正的问题
- Prompt Inspector 已生成但设置页不可见 -> 预览成功后自动切到剧情档案页。
- 未分析章节 placeholder 被误判 stale -> missing/PARTIAL 与 stale 分离。
- 结构化人物/关系对象直接显示 JSON -> 改为人类可读文本。
- 章节序号/标题/状态挤在一起 -> 三列 grid 对齐。
- Default Theme 写 attribute 会压平 v1.2 外观 -> Default 彻底不注入主题 override。
- TXT 增加 UTF-8 BOM / UTF-16LE / strict UTF-8 / GB18030 浏览器端解码。
- interrupted / incomplete Draft 的手动继续复用原 Generation，不新建重复生命周期。
- Generation 输入章节 revision/hash 在继续与采纳时再次校验；章节被修改后旧 Draft 不得覆盖新正文。
- Novel 项目 CSS 只通过 Novel scope 编译后注入，禁止越界改写全局 UI。
- maxAppendAttempts 规范化为有限 0..8，缺省值固定 3，避免 NaN 破坏补写上限。
