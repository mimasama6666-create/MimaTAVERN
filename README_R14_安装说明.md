# 咪嘛馆 R14：酒馆界面与正则兼容续修

此包接续 R13，只包含咪嘛馆程序，不包含真实聊天、API Key、浏览器数据库或其它项目。

## 覆盖方式

将本 ZIP 内的文件和目录合并到现有咪嘛馆网站根目录，`index.html` 保持在原位置。必须同时上传 `vendor/` 目录与新增的 `compat-markdown.js`、`compat-regex-ui.js`；不要只替换 HTML/CSS。保留现有用户素材、主题与配置文件。没有替你发布网站或推送仓库。

更新后重新加载网页；如旧网页仍停留在后台，关闭旧标签再打开。不要清除网站数据、IndexedDB 或本地存储。新资源引用带 R14 缓存版本；本包未迁移或清空数据库。

## 本轮可用

- 手机故事库、开场预览、角色资料、设置和可滚动工具面板；输入区恢复全宽。
- 导入酒馆单条正则 JSON，编辑、测试、开关和排序；修改只影响当前故事覆盖，原卡不改。
- 正则分清源副本、显示、发送阶段，支持双开关、实际历史深度及已实现宏；失败显示具体规则与来源。
- Markdown、安全 HTML/CSS 与本地正文字体衔接；长文显示出错时保留全文并明确提示。

这不是完整 SillyTavern/Tavern Helper 宿主。依赖任意作者 JavaScript、完整 Zod/MVU、全套 STscript 或服务端扩展的复杂卡，仍可能缺少互动能力；没有把这些功能伪装成已兼容。卡内内容和外置预设仍保留，兼容聊天没有额外默认创作提示词注入。

## 验证与限制

使用匿名卡片、本地 Chromium、真实 IndexedDB/Worker 和假 Provider 验证；未调用付费模型。未实测真实 iPhone/WebKit，也没有拿到截图所对应的原始私有角色卡，不能宣布该卡已全部正常。

完整根因、能力矩阵、测试及下一阶段宿主蓝图见配套《R14_施工验收与高级兼容蓝图.md》。回退请使用配套回滚程序包，不要删除聊天数据。
