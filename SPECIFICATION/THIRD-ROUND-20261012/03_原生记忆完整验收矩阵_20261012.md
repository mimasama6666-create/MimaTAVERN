# 原生记忆 P0/P1 完整验收矩阵

说明：下列为**下一轮必须执行的验收标准**，不是目前已经通过的清单。当前独立验证仅包括源码、两项旧 smoke 和随附一项 mock replay。

| ID | 场景 | 必须观察的用户能力或真实状态 | 推荐测试方法 |
|---|---|---|---|
| MEM-01 | 总结中立即发送剧情 | 主回合照常生成、显示、入库，记忆任务继续；没有 toast 阻塞 | 浏览器脚本+慢模型 stub |
| MEM-02 | 事实多分段运行时连续发三轮 | 顺序和内容正确、无重复/覆盖、总结只涵盖锁定原文 | 异步请求分闸并发 |
| MEM-03 | 核心记忆运行中切设置 Tab/关闭弹窗 | 任务不被取消；可查看进度、停止；聊天正常 | UI 自动化 |
| MEM-04 | 总结过程中切换 session | 记忆归属原 session，不能出现在新 session；新剧情可发送 | 多会话 UI + DB 对照 |
| MEM-05 | 页面刷新/浏览器崩溃后重开 | 已保存 journal 为 pending/interrupted 可恢复/明确失败；不假装仍在后台 | 浏览器重启/本地 DB |
| MEM-06 | 手工编辑核心记忆后迟到自动结果 | 手工编辑优先，不被覆盖；冲突显式、可重做 | 模型异步回放 |
| MEM-07 | 总结中追加新消息 | 新消息完整保留，已总结覆盖范围明确，未被默认为已总结 | CAS + 浏览器 |
| MEM-08 | 总结中编辑/删除/分支重说旧消息 | 摘要 stale，禁止将旧分支总结当成当前事实 | 来源 hash/ID 对照 |
| MEM-09 | HTTP 200 content 空 | 分类为空回复，旧记忆不变、显示 finish_reason、阶段与诊断 | Mock SSE/JSON |
| MEM-10 | HTTP 200 仅 reasoning_content/拒绝 | 不当作正文/事实提交，错误分类明确、无暗中换模型 | Mock API |
| MEM-11 | HTTP 400 参数不兼容 | 真实 payload 的字段差异可查，错误不是泛泛“上游失败” | 400 stub + 设置 A/B |
| MEM-12 | HTTP 429、408、5xx、DNS/跨域 | 独立后台失败，主剧情不被记忆控制阻断；保持最后已验证结果 | 故障注入 |
| MEM-13 | API 正文已生成，DB 写入失败 | 显示保存失败，不显示“记忆已完成”；可安全再次提交或重新生成 | 注入写入错误 |
| MEM-14 | 长剧情事实 50/200/500 轮 | 完整覆盖来源段，阶段有界，API 次数/耗时可见，失败可恢复 | 性能数据+真值区间 |
| MEM-15 | 核心记忆从 facts/context 分别生成 | 正确关联来源及版本；重复、冲突、不完整标志清晰 | Prompt trace + 定向测试 |
| MEM-16 | 自动 Rolling Summary 触发 | 主剧情不等待其模型返回，摘要单独结算且不会跳过未覆盖区间 | 长旧历史模拟 |
| MEM-17 | Prompt 实际注入 core/facts | Inspector 显示引用 ID/轮次/字符；按开关及预算确实生效 | 真实 assemble 截图 |
| MEM-18 | 无/有记忆对照问答 | 真值召回率和误记率可量化，并检验新旧事实矛盾处理 | 角色卡独立 3 集 |
| MEM-19 | 原生小说记忆与兼容实验室并行 | 不串入另一项目、不阻断原生主回合、不丢存档 | 跨界测试 |
| MEM-20 | 旧导出、导入及无记忆老存档 | 旧字段和原生所有能力保持，缺失≠清空 | fixture 回归 |
| MEM-21 | 跨 Tab 同时记忆+剧情 | 不覆盖新主库修订，不出现双 commit 或数据重置 | 真 IndexedDB 多标签 |
| MEM-22 | 同一任务停止/重试/页面恢复 | 唯一 jobId/attemptId、至多一次结算、旧 attempt 不覆盖新 | 故障回放 |
| MEM-23 | MIMAMAO/QQBOT 边界 | 不修改两项目代码/数据；普通咪嘛馆零新部署负担 | 变更清单与文件差异 |
| MEM-24 | 旧第二轮缺陷回归 | CSS 切换不丢回复、external CSS 生效、abort 不报 failed、正则不拖死 | 上一轮所有用例 |

必须区分 SOURCE_PASS / OFFLINE_PASS / BROWSER_PASS / API_PASS / WINDOWS_PASS，报告逐项标明；没有端到端证据绝不填 FULL PASS。每项保留首次非法状态产生点、传播链、最终用户可见结果。
