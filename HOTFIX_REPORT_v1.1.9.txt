MIMAMAO Tavern v1.1.9 · SAFE HTML DYNAMIC STATUS VARIABLE HOTFIX
=================================================================

Baseline
--------
Unique source baseline: MimaTAVERN-main-v1.1.8-FULL.zip.
This hotfix is additive and narrowly scoped. No unrelated refactor/cleanup was performed.

Symptom
-------
BOND numbers rendered correctly (for example 85 / 100), but every visual meter remained empty.
Changing the CSS alone could not fix it.

Root cause
----------
The v1.1.8 Safe HTML sanitizer intentionally allowed only:
  class, title, role, open, colspan, rowspan, scope, data-*, aria-*
and removed every `style` attribute.

The established BOND HTML encodes its dynamic percentage as:
  <span class="mima-meter-fill" style="--value:85%;"></span>

Therefore Safe HTML transformed that element into:
  <span class="mima-meter-fill"></span>

The CSS then evaluated `width: var(--value, 0%)`, hit the fallback, and rendered 0% for every bar.

Fix
---
- Added a narrow Safe HTML inline-style bridge.
- It does NOT allow arbitrary inline CSS.
- It preserves only the legacy custom property `--value`.
- `--value` must be a percentage and is clamped to 0..100.
- Every other inline declaration is discarded exactly as before.
- Existing tag/attribute/event/javascript filtering remains intact.
- Existing HTML, Regex, CSS output contract and BOND markup do not need to change.
- Advanced static asset release marker to 1.1.9 so iOS/WebView does not keep the v1.1.8 app.js sanitizer in cache.

Regression
----------
- Existing v1.1.0 through v1.1.8 smoke suites rerun unchanged.
- New v1.1.9 smoke verifies the controlled style bridge, percentage-only validation, 0..100 clamping, continued rejection of arbitrary style allowlisting, and cache-bust advancement.
