入门 / 5 步操作
🚀

第一次来

从空白页面开始，五步内和喜欢的角色说上话

  1. 01
    确认进入主页

    先找到屏幕顶端的「剧情 · 功能 · 设置」，手机上也能看到。

  2. 02
    打开 API 设置

    点「设置」，再选「🔌 API（接口）」。输入你使用的服务商地址、密钥和模型，保存。

  3. 03
    创建剧情

    点左上「☰ 剧情」→「＋ 新建剧情」。给剧情起名字并创建。

  4. 04
    选择角色和自己

    「设置 → 🤍 角色」导入或创建角色卡及玩家面具，为当前剧情应用挂载。

  5. 05
    开始聊天

    回到剧情输入框，写一句话后点「➤ 发送」。

✓ 做对了会怎样你在剧情里看到了自己的发言和角色回复，就是成功啦。

↪ 不对劲时先检查如果角色不回话，先到「设置 → API」检查模型与连接；不要反复连点发送。

再多知道一点 ⌄

不需要先学世界书、正则或编程；先能聊天再研究高级设置。

玩下载的酒馆角色卡

手里只有一张 PNG？从这里开始

  1. 01
    打开酒馆入口

    点页面顶部「功能」→「🎴 玩酒馆角色卡」，也可以从剧情侧栏进入。

  2. 02
    选择角色卡

    在兼容游玩页点击「选择 PNG / JSON / CHARX」，选你的文件。

  3. 03
    确认人物和开场

    按页面提示选择角色卡版本、开场白及玩家称呼。

  4. 04
    创建并开始

    保存或进入故事，像普通聊天一样在底部发送消息。

✓ 做对了会怎样看到角色的开场白、可以输入聊天，就是打开成功。

↪ 不对劲时先检查酒馆兼容模式的故事和原生剧情是两套存档，请分别备份。

再多知道一点 ⌄

角色卡里的全部外部脚本不保证可执行；“成功导入”不等于第三方插件百分百兼容。

API 和模型怎么填

不懂技术也能分清这四个东西

  1. 01
    打开接口页

    「设置 → 🔌 API（接口）」。

  2. 02
    填 API 地址

    复制服务商提供的接口地址，不要随便拼凑路径。

  3. 03
    填密钥和模型

    粘贴 API Key，并填写或选择服务商真正支持的模型名称。

  4. 04
    保存并试用

    保存设置，按界面可用的测试入口核对，然后回剧情发送一句短消息。

✓ 做对了会怎样短句可以正常返回就说明基础通路可用。

↪ 不对劲时先检查若提示 CORS / Failed to fetch，说明浏览器请求可能被服务商拒绝；不需要清空网站数据。

再多知道一点 ⌄

模型“上下文总窗口”与“最大输出字数”不是一个数；发送一次可能产生模型费用。

挂载角色、面具、预设

导入后不生效？最常见原因是没挂载

  1. 01
    进入角色设置

    打开「设置 → 🤍 角色」，导入角色卡及自己的 User Persona。

  2. 02
    选当前剧情

    先确定现在打开的是你准备游玩的剧情。

  3. 03
    应用挂载

    在角色设置里选中要使用的角色与玩家面具，并点击应用挂载。

  4. 04
    进一步丰富

    预设在「设置 → 🧩 预设」，世界书在「设置 → 📚 世界书」，同样要为剧情启用或挂载。

  5. 05
    最终核对

    「设置 → 🔬 Prompt（提示词）」查看本轮真实使用的材料。

✓ 做对了会怎样Prompt 检查器里能看到角色和设定的实际注入情况。

↪ 不对劲时先检查资源库有内容，不代表当前剧情已经在用。

再多知道一点 ⌄

世界书条目还取决于触发条件和预算；“挂上了”也不保证每条都会进入本轮请求。

百宝箱：一键发指令

比如“推进剧情”，以后再也不用反复打字

  1. 01
    找小图标

    回到剧情底部，找到发送箭头「➤」左边的「🪎」。

  2. 02
    添加一条指令

    点「新建指令」，填写名字，例如「推进剧情」，再输入要说的话。

  3. 03
    选发送方式

    「发送」会立即按正常用户消息发送；「仅填入」只把文字放进输入框供你修改。

  4. 04
    保存并使用

    保存后从百宝箱点对应指令。你也能导入、导出 JSON 指令集。

✓ 做对了会怎样指令像自己发送的普通消息一样进入当前剧情。

↪ 不对劲时先检查模型正在生成时，系统会防止重复提交。

再多知道一点 ⌄

已有的输入框草稿不应被“快捷发送”清掉；如果你想先看看内容，请选「仅填入」。

小剧场：开场前的卡片

展示介绍、欢迎页，或做可以点击的互动卡片

  1. 01
    打开管理

    「设置 → 🎭 小剧场」，或者「🪎 百宝箱 → 小剧场」。

  2. 02
    创建素材

    点新建，或者导入 .html / .htm / .js 文件。初次可以先用内置示例。

  3. 03
    挂载到剧情

    选中「当前剧情」，保存并挂载。不同剧情能用不同小剧场。

  4. 04
    返回聊天

    小剧场会显示在角色开场白之前，不占一条普通聊天消息。

✓ 做对了会怎样你能在聊天开头看到小剧场卡片。

↪ 不对劲时先检查普通静态 HTML 不需要开启危险权限。

再多知道一点 ⌄

陌生 JS 默认不能执行。只有充分信任时才授权脚本；读取完整剧情原文还需要单独授权。授权后脚本可能联网。

换主题、字体和壁纸

只想让咪嘛馆变漂亮？走这条路

  1. 01
    先看普通外观

    「设置 → 🎨 外观」，选择内置主题、字体、字号和已有的自定义 CSS。

  2. 02
    想自己捏主题

    点顶部「功能 → 🎨 可视化主题工坊」。

  3. 03
    挑模板并编辑

    从模板开始，选择“想改哪里”，在“常用外观”调色、背景、按钮等。

  4. 04
    真实试穿

    在工坊里检查视觉效果；还不满意可以撤销，再调整。

  5. 05
    正式应用

    确认满意后点「应用全局主题」等正式应用/发布操作。

✓ 做对了会怎样退出工坊后，主剧情也使用了新主题，才叫应用成功。

↪ 不对劲时先检查仅试穿或保存草稿，不等于正式发布。

再多知道一点 ⌄

换上自定义 CSS 后某处仍有灰底，可以在工坊试试「隐藏多余容器底色」，先预览再应用。

按钮动画和自定义音效

想换成猫爪粒子、可爱点击声？

  1. 01
    打开声音开关

    「设置 → 🎨 外观 → 动画与点击音效」。

  2. 02
    挑动画或静音

    动画、声音可以分别关闭；声音可以调音量。

  3. 03
    导入自己的声音

    分别给「普通按钮」「发送/继续/推进」「菜单/设置」导入声音文件。

  4. 04
    试听与恢复

    点击“试听”确认效果；不喜欢点「恢复主题声音」。

  5. 05
    高级配方

    工坊「交互音效」还能调整粒子、动效时长与每套主题自己的音频。

✓ 做对了会怎样点击按钮时按你的设置发出动画和声音。

↪ 不对劲时先检查音频文件最大 4MB；能否播放还取决于浏览器和设备静音状态。

再多知道一点 ⌄

个人覆盖声音与主题原声音是两层设置，换主题后个人音效仍会保留。

长剧情与记忆

剧情很长，为什么 AI 有时忘事？

  1. 01
    先确认原文还在

    本地 History 与单次发给模型的 Prompt 是两回事；超窗不等于删除存档。

  2. 02
    检查 Context

    「设置 → 🧠 Context（上下文）」看原文轮次、容量和预算。

  3. 03
    管理记忆

    「设置 → 🗃️ 记忆」查看剧情摘要、核心记忆与事实记忆。

  4. 04
    手动整理

    决定是否总结，先看提示的请求次数和费用规划，再执行。

  5. 05
    失败时查草稿

    记忆 → 记忆任务诊断与安全恢复 → 未通过验收的生成原文。

✓ 做对了会怎样正式记忆只有通过检查后才会写入；失败原文可查但不自动当成事实。

↪ 不对劲时先检查有些总结需要真实 API 调用，可能收费。

再多知道一点 ⌄

别为了“省 Token”随便清除剧情历史；先确认记忆是否确实覆盖了重要情节。

正则：隐藏某些词

例如不想在显示正文里看到“极其”

  1. 01
    打开正则

    「设置 → 🧬 正则」。

  2. 02
    建立规则

    模式填「极其」，替换内容留空，并选择“显示 / display”阶段。

  3. 03
    先测试

    在即时测试框输入带“极其”的句子，点「运行当前草稿」。

  4. 04
    保存、启用、挂载

    确保规则自身启用、规则包启用，并挂到当前剧情。

  5. 05
    回到正文看

    重新查看渲染，确认只影响你希望处理的内容。

✓ 做对了会怎样显示里的“极其”被过滤就对了。

↪ 不对劲时先检查显示正则只修改页面看起来的效果，不等于修改原始存档。

再多知道一点 ⌄

新手先只用显示阶段；发送前、保存前和 Prompt 阶段可能改变模型实际接收的内容。

写小说：生成与采纳

AI 写出来 ≠ 自动覆盖你的正式正文

  1. 01
    打开小说

    顶部「功能 → ✒ 小说创作」。

  2. 02
    建立小说

    选导入 TXT 或新建空白项目。

  3. 03
    选章节续写

    在“章节 / 正文”里选择目标章节，生成候选草稿。

  4. 04
    先检查后采纳

    确认没有乱写、重复或偏题后，点「✓ 采纳」，才写入正式正文。

  5. 05
    维护剧情档案

    到“剧情档案”整理人物关系、伏笔和时间线。

✓ 做对了会怎样小说的正式正文增加了采纳的段落。

↪ 不对劲时先检查失败时先看是否已经采纳成功，不要连点重复生成/采纳。

再多知道一点 ⌄

续写和档案整理可能单独调用 API；小说工程与普通聊天不完全是一回事。

如何备份？先看这章！

推荐整馆归档；旧 JSON 入口按各自范围保留

推荐：一份整馆归档在「设置 → 数据备份」选择「导出整馆归档」，保存 .mimatavern 文件。包含原生剧情、酒馆兼容库、小手机和媒体原件，以及工坊、字体、壁纸、个人音效和工具草稿。导出时先暂停编辑与生成。

换设备恢复选择「预检整馆归档」，查看冲突后点「继续已预检恢复」。只新增缺失记录，同一条资料内容不同会停止并说明；已有界面偏好优先。各库分阶段提交，中断后可在本页继续；看到全部完成再刷新页面。原有 JSON 备份仍按下面方式使用。

  1. 01
    备份原生剧情

    「设置 → 💾 Data（数据）」→「导出剧情与设置」，把文件保存到手机“文件”里。

  2. 02
    备份酒馆兼容剧情

    进「🎴 玩酒馆角色卡」的备份/恢复区；可选兼容单库或双库备份。

  3. 03
    备份小手机

    进入小手机“我的”相关备份入口，单独导出手机数据。

  4. 04
    检查文件确实存在

    看到实际文件在设备上，才算备份完成；建议在更新和换设备前做。

✓ 做对了会怎样你应该拿到对应的真实备份文件。

↪ 不对劲时先检查只导出“原生剧情与设置”并不等于已经备份小手机及酒馆兼容库。

再多知道一点 ⌄

跨设备没有自动同步保证。恢复出现“部分成功”时先检查已恢复的内容，不要立即重复覆盖。

出问题了怎么办

先保住数据，再查问题，不要乱删

  1. 01
    别连续按发送

    若生成卡住，查看进度、已收到的草稿和“免费核对原任务”。

  2. 02
    界面怪怪的

    先留截图、版本信息；不要为了刷新 CSS 直接清除网站数据。

  3. 03
    AI 不认角色

    到「设置 → 🔬 Prompt」看实际注入，确认挂载和世界书触发。

  4. 04
    读流式 HTML 被拉走？

    阅读时可以暂停跟随，要追最新内容再点「↓ 跟随输出」。

  5. 05
    真的要恢复

    先查看备份回执，分清主库成功和某项素材失败的情况。

✓ 做对了会怎样旧剧情还在、错误信息可查，就有机会安全处理。

↪ 不对劲时先检查真机 Safari、复杂第三方主题与跨库迁移仍属于开发测试边界。

再多知道一点 ⌄

禁止用“清除网站数据”当万能修复，更不要把 API Key 或私人 Prompt 发给陌生人。

💬 最常问的八个问题

点哪儿能看使用手册？

从顶栏“功能 → 📖 使用手册”或“设置 → 📖 使用手册”打开；酒馆兼容页的工具菜单也有入口。

别人给了 PNG 角色卡，我应该用哪个按钮？

点“功能 → 🎴 玩酒馆角色卡”，选择 PNG/JSON/CHARX。不要只在原生资源检查器里浏览却忘记创建故事。

为什么我设置了角色，AI 还是不认识？

检查当前剧情是否“应用挂载”。再去“设置 → 🔬 Prompt（提示词）”看这次请求实际带了什么。

我调了 CSS，为什么没变化？

先看是否只是“预览 / 试穿”。工坊要明确“应用全局主题”之后才改变正式界面。

我打开流式 HTML 后怎么不跟着往下走了？

这是阅读保护。想再次追随新文字，点击剧情里的“跟随输出”。

手机换了/清除网站数据，会自动恢复存档吗？

不会。原生剧情、酒馆兼容库、小手机分别导出文件，再在新设备各自恢复。

百宝箱发送和仅填入有什么区别？

“发送”就是像你亲自发了一条消息；“仅填入”不会发送，你可以先修改正文。

陌生 JS 小剧场可以放心点授权吗？

不建议。运行 JS 和读取原文是不同权限；JS 有可能联网。只授权可信、能确认用途的脚本。

📚 看不懂这些词？

剧情 / Session
一段独立聊天，不同剧情可以有不同人设。
角色卡 / Character Card
角色的身份、说话方式、开场等资料。
玩家面具 / Persona
AI 眼中的“你”是谁。
API
模型服务商给你的聊天接口，需要自己配置。
Prompt
